# 📊 ETF 포트폴리오 리밸런싱 도구

매달 ETF 포트폴리오를 관리하고 리밸런싱하는 웹 애플리케이션입니다.

## 주요 기능

- **다중 계좌 관리** — IRP, 퇴직연금, 연금저축 등 여러 계좌 관리
- **자동 시세 조회** — Yahoo Finance / Naver Finance에서 한국 ETF 현재가 자동 조회
- **리밸런싱 계산** — 목표 비율에 맞춰 매수/매도 수량 자동 계산
- **30일 추세 차트** — 각 종목의 30일 스파크라인 차트
- **현금 및 납입액 관리** — 현금 잔액 + 월 납입액 기반 리밸런싱 가용 금액 계산
- **수동 가격 입력** — API 조회 실패 시 직접 현재가 입력 가능
- **CSV 내보내기** — 현재 포트폴리오 데이터를 CSV로 내보내기

## 사용 방법

### 1. 설치

```bash
cd portfolio-rebalancer
npm install
```

### 2. 실행

```bash
npm start
```

### 3. 브라우저에서 접속

```
http://localhost:3000
```

## 사용 흐름 (매달 리밸런싱)

1. **현금 잔액 입력** — 계좌의 현재 현금 잔액 입력
2. **월 납입액 확인** — 이번 달 추가 납입 예정 금액 확인
3. **시세 새로고침** — 상단 🔄 버튼으로 현재가 조회
4. **추가 주문 수 확인** — 각 종목의 "추가 주문" 칸에서 매수/매도 수량 확인
5. **주문 실행** — 증권사 앱에서 해당 수량만큼 거래

## 포트폴리오 설정

- **계좌 추가** — 상단 "+ 계좌 추가" 버튼
- **종목 추가** — 계좌 카드의 "+ 종목 추가" 버튼
- **종목 편집** — 종목 행 클릭 → 수량, 평단가, 목표 비율 수정

## API 조회 실패 시

시세 자동 조회가 안 될 경우:
- **✏️ 가격 일괄 입력** 버튼으로 현재가를 직접 입력
- 또는 종목 행 클릭 → "현재가 직접 입력" 필드 활용
- 수동 입력된 가격은 "수동" 배지로 표시됩니다

## 데이터 저장

모든 포트폴리오 데이터는 **브라우저 localStorage**에 저장됩니다.
서버를 재시작해도 데이터가 유지됩니다.

## 기술 스택

- **Backend**: Node.js + Express
- **Price Data**: Yahoo Finance (yahoo-finance2) + Naver Finance (fallback)
- **Frontend**: Vanilla HTML/CSS/JavaScript (프레임워크 없음)
- **Charts**: HTML5 Canvas sparklines
